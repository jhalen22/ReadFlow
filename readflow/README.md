# ReadFlow (Frontend Scaffold)

A structured and interactive reading & comprehension learning platform for
Grade 5 learners — Capstone Project, Cebu Technological University.

This scaffold currently includes three routes:

- `/` — Landing Page
- `/login` — Log In
- `/signup` — Sign Up

Built with **React + TypeScript + Vite + Tailwind CSS + React Router**.

See the setup guide provided alongside this project for step-by-step
VS Code instructions.
